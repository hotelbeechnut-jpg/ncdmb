# MASTER BUILD PROMPT: Seminar Recap Website

You are a senior front-end engineer and motion designer. Build a premium, mobile-first, motion-rich recap website for a 5-day digital marketing skill acquisition seminar. Work autonomously. Do not ask questions; where information is missing, use the placeholders defined in the config file and list your assumptions at the end.

---

## 1. Purpose

This site is a **recap of the seminar** and, quietly, a **live demonstration of what a professional website feels like**. It is shown first to the seminar organizers' admin for approval, then shared inside the seminar's WhatsApp group of 50+ small business owners. They are mostly on mid-range Android phones, opening the link inside WhatsApp's in-app browser on mobile data.

Two jobs, in this order:
1. Make attendees proud of the event: a beautiful, accurate recap of all five days.
2. Make them want their own website: a pitch section for **Talent Loop Webdev Services**, the builder.

The site itself is the pitch. It must feel expensive, fast and smooth. A laggy site defeats the purpose, so performance wins every conflict with spectacle.

## 3. Tech stack

- React + Vite (JavaScript or TypeScript, your choice; keep it consistent)

- **Lenis** for smooth scrolling (disabled when `prefers-reduced-motion` is set)

- Deploy target: **Cloudflare Pages**, connected to GitHub.
- **No Three.js / WebGL.** All "3D" is CSS 3D transforms (perspective, rotateX/Y, translateZ) driven by Framer Motion.

## 5. Media pipeline (`scripts/build-media.mjs`)

I will drop raw files into `media-source/dayN/images|videos`. Counts vary a lot between days (some days have only a few images, others dozens). **Do not hardcode counts.** The script must:

1. Scan `media-source/day1` to `day5`. Missing or empty folders are valid (Day 4 media and all of Day 5 arrive later).
2. **Images:** convert to WebP at three widths (480, 960, 1600), preserving aspect ratio and honoring EXIF rotation. Also generate a ~24px blurred placeholder (base64) for each. Record width and height.
3. **Videos:** transcode to H.264 MP4, max 720p width on the long edge, CRF ~28, `-movflags +faststart`, audio kept but low-bitrate AAC. Generate a poster frame (WebP) at about 1 second. Record duration. Each output file **must stay under 20 MB** (Cloudflare Pages limit is 25 MB per file). If a video exceeds that after compression, lower the quality or trim, and log a clear warning with the file name.
4. If `ffmpeg` is not installed, skip videos with a clear warning and still process images. Do not crash.
5. Files whose names start with `featured-` are flagged `featured: true`. Everything else is `featured: false`.
6. Write `src/data/media-manifest.json`:
   ```json
   { "day1": { "images": [{ "id", "featured", "w", "h", "blur", "srcset": {...} }], "videos": [{ "id", "featured", "duration", "poster", "src" }] }, "day2": {...} }
   ```
7. Sort deterministically (featured first, then filename).
8. Expose `npm run media` and run it automatically before `npm run build`.
9. Add `media-source/` to `.gitignore`.

The UI must adapt to counts:
- **0 media** for a day: show the "Media coming soon" state.
- **1 to 6 items:** a single spotlight layout with a short filmstrip.
- **7 or more:** the 3D carousel built from featured items (or the first 10 if none are flagged) plus a "View all" lightbox grid with lazy loading.

## 6. Design system

**Mood:** clean, confident, premium. White-dominant canvas with deep purple moments. Generous whitespace, large type, restrained effects.

**Color tokens (CSS variables, then Tailwind theme):**
```
--white:        #FFFFFF
--paper:        #FAF8FF   /* off-white section background */
--lavender-100: #F1ECFF
--lavender-300: #CBB8FF
--purple-500:   #7C3AED
--purple-700:   #5B21B6
--purple-900:   #2E1065   /* dark sections */
--ink:          #1B1230   /* body text on light */
--gold:         #F5B93B   /* single accent for CTAs and key highlights */
```
Alternate light sections (white/paper) with dark sections (purple-900 with subtle radial gradient glow). Use gold only for primary CTAs and a few highlights. Ensure WCAG AA contrast everywhere.

**Typography:** Sora for headings (tight tracking, large scale, `clamp()` sizing), Inter for body. Use big numerals ("01"-"05") as graphic elements for the days.

**Surfaces:** soft glass cards (backdrop blur used sparingly; it is costly on low-end phones, so provide a solid fallback), thin 1px borders, large radii (20-28px), layered soft shadows. Add a very subtle grain overlay (tiny tiled PNG or CSS noise) on dark sections only.

**Motion language:** ease-out, spring-based (`stiffness ~120, damping ~20`), staggered reveals, nothing bouncy or gimmicky. Durations 0.5-0.9s for reveals. Motion should feel weighty and calm.

## 7. Page architecture (single page, in this order)

1. **Preloader.** Branded wordmark and a numeric counter (0-100%) tied to real asset loading of the hero. Maximum 1.8s visible. Skip it on repeat visits in the same session (try/catch storage). Exits with a smooth purple wipe.

## 9. Content (`src/data/days.js`)

Write these as data objects: `{ n, title, subtitle, headline, takeaways[], mediaKey, status }`. These are our own summaries. Do not add slide wording beyond this.

**Day 1: Digital Marketing Foundations**
- Headline: "You don't own your Instagram."
- Takeaways:
  - Digital marketing is a strategy for getting the right message to the right person and moving them to act. Posting is only one activity.
  - "Everyone" is not a customer. Narrow your audience by age, budget, needs and occasion.
  - People buy because of a sudden event, an ongoing frustration or a planned decision, and trust usually comes before the sale.
  - Customers move from awareness to interest, consideration, action and loyalty. Pushing for a sale too early breaks the journey.
  - Choose channels by audience, objective, content and resources, not by whatever is popular.
  - Social platforms are rented space. Your website and email list are assets you control.

**Day 2: Content Creation Fundamentals**
- Headline: "Make people stop, trust you, and message you."
- Takeaways:
  - Content is whatever speaks for your business when you are not in the room.
  - Every piece has a job: educate, entertain, inspire, connect or convert.
  - A strong post follows hook, body and call to action.
  - Start with the audience and a clear niche, not with what you feel like posting.
  - You do not need an expensive camera or thousands of followers to begin.
  - Plan a weekly calendar, repurpose one idea in many formats, measure what matters, and stay original and ethical.

**Day 3: Platforms & Social Media Marketing**
- Headline: "Don't be everywhere. Be where your customers respond."
- Takeaways:
  - A platform is a place where people gather. Being on one is not a strategy.
  - Think of the platforms as market spaces: WhatsApp is the shop counter, Facebook the town hall, Instagram the shop window, TikTok the busy motor park, YouTube the library.
  - Use the four-question filter (who, what, how, can I sustain it) and start with one primary and one support platform.
  - WhatsApp Business tools such as the catalog, quick replies, labels and Status turn chats into sales.
  - Confirm payment in your actual bank or payment app, never from a transfer screenshot.
  - Finish with a one-week plan: a goal, three pillars, clear calls to action and one metric to watch.

**Day 4: Tools & Hands-On Creation**
- Headline: "Done is better than perfect."
- Takeaways:
  - Tools are a means to an end. Finished posts beat a phone full of unused apps.
  - Think in six drawers: capture, design, video, think and write, channels, and measure and organize.
  - Better phone photos come from a clean lens, good light, simple backgrounds, steady hands and choosing the best of many shots.
  - In Canva, keep one message per design, two or three colors, readable fonts and the right size for the platform.
  - Short vertical videos in CapCut become clearer when you cut dead air and add readable captions.
  - Use AI for ideas and first drafts, then verify claims before you publish.
- Media status: `coming-soon` until media exists.

**Day 5: Distribute, Sell & Measure**
- Status: `coming-soon`. Teaser: "The final session brings it together: getting your content out, turning attention into sales, and measuring what works."

## 10. 3D and motion specifications (with performance guardrails)

Implement these as reusable components:

- **`FloatingGallery3D` (hero):** 7-9 absolutely positioned cards inside a `perspective: 1200px` container, each with its own `translateZ`, slow float loop (sine drift, 6-10s), and pointer-driven `rotateX/rotateY` using `useMotionValue` and `useSpring`. On touch devices, replace pointer tilt with a gentle automatic float.
- **`Carousel3D` (day modules and gallery):** coverflow with the active card centered and neighbors rotated on Y (about ±35°), pushed back on Z, scaled down and dimmed. Drag with momentum, snap to the nearest card, arrow-key and button navigation. Render at most 5 cards at a time (virtualize).
- **`DayChapter`:** giant numeral parallax, staggered takeaway reveals, and a media module that picks its layout by count (section 5).
- **`Lightbox`:** full-screen viewer with swipe, pinch-friendly images, video with controls, focus trap, Escape to close.
- **`Reveal` / `SplitText`:** reusable scroll-reveal primitives.
- **Scroll progress bar** at the top and animated day-indicator dots.

**Guardrails:**
- Animate only `transform` and `opacity`. Use `will-change` sparingly. No layout-thrashing animations.
- Honor `prefers-reduced-motion`: replace 3D drift, parallax and Lenis with simple fades.
- Detect low-end devices (`navigator.hardwareConcurrency <= 4` or `deviceMemory <= 2`, if available) and automatically reduce card counts, disable blur effects and pause background video.
- Videos: `muted`, `playsInline`, `preload="none"`, poster images required, start only when in view (IntersectionObserver), and at most one playing at a time.
- Images: use `srcset`/`sizes`, `loading="lazy"` and `decoding="async"`, and show the blur placeholder until loaded. The hero's first image is eager.
- Keep the initial JS bundle lean: code-split below-the-fold sections with `React.lazy`, and import only what you use from libraries.
- Target on a mid-range Android over 4G: first meaningful paint under 2.5 seconds, interactions at a steady 60fps, and total initial transfer under about 3 MB before scrolling.
